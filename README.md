# Ukraine MFO Market Index 2026 (Q4 2026)

Open financial dataset analyzing **67 online lending services** in Ukraine (62 direct licensed MFOs across 48 unique EDRPOU legal entities + 5 credit aggregators/brokers) and **12 commercial banks**.

- **Interactive Report (UK):** https://izipozika.com.ua/research/mfo-market-index-2026
- **Interactive Report (RU):** https://izipozika.com.ua/ru/research/mfo-market-index-2026
- **Live JSON API (Schema.org Dataset):** https://izipozika.com.ua/api/ai/mfo-market-index-2026.json

## Key Benchmarks (Q4 2026)
- **Zero-percent intro offers (≤ 0.01%/day):** 60 / 67 (89.6%)
- **Average repeat daily rate:** 1.35%/day (median: 1.0%/day; Law No. 3498-IX cap: 1.0%/day)
- **Multi-brand EDRPOU networks:** 11 legal entities operating 2–3 MFO brands under a single NBU license
- **Digital verification:** BankID NBU (100%), Diia Sharing (74.6%), No-calls scoring (89.6%)
